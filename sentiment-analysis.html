Sentiment Analysis

About this project

This aim to predict whether a given piece of text has a positive or negative sentiment i.e. the emotions that the author is conveying. It uses a multinomial Naive Bayes algorithm to make it's predictions. The vocabulary used is Python's NLTK (Natural Language Tool Kit) sentiment lexicons - both positive and negative put together. Due to the limited nature of this vocabulary (e.g. no slang words), this algorithm works better with larger inputs.

Next steps

In future development I would like this algorithm to attempt to predict to degree of the sentiment e.g. very negative, mildly positive, 70% positive etc. Additionally, I need to go though the vocabulary to add new slang terms and perhaps remove older redundant ones. To further increase performance I should reduce each word to their root form through stemming and remove any duplicates, both in the vocabulary and the user input.
